## 📁 Repository Structure & Projects

| Directory | Description | Technologies |
| :--- | :--- | :--- |
| **`Calculator/`** | Calculator application implemented using the **Model-View-Controller (MVC)** design pattern. | Java Swing, AWT, MVC Architecture |
| **`JSP/`** | Jakarta Servlet and JavaServer Pages (JSP) web application running on Apache Tomcat. | JSP, Jakarta Servlets, JSTL, Tomcat |
| **`RMI/`** | Distributed Computing application using **Remote Method Invocation (RMI)** with Client and Server implementation. | Java RMI, Remote Interface |
| **`server client/`** | Multi-threaded client-server networking application utilizing Java TCP Sockets. | Java Sockets, TCP/IP Networking |
| **`servett project 2/`** | Modern Java Servlet Web Application configured with Embedded Apache Tomcat and Maven. | Jakarta Servlet 6.0, Embedded Tomcat, Maven |
| **`shopsphere_project/`** | Advanced Java E-Commerce Management System with dual persistence (File Serialization, CSV, MySQL JDBC) and CLI/Web interfaces. | Core Java, Collections, JDBC, Serialization, OOP |
| **`student(JDBC)/`** | Student Registration Form with GUI and MySQL Database integration using JDBC. | Java Swing, MySQL, JDBC |

## 🚀 Getting Started

### Prerequisites
- **Java Development Kit (JDK 17 or 21+)**
- **Apache Maven 3.8+** (for Maven projects)
- **MySQL Database Server** (for JDBC modules)

### Running a Project
Each module is self-contained. Navigate to any project folder and follow the instructions in the respective folder's `README.md` (or run scripts such as `run_app.bat` or `run_web.bat`).
